# Brand identity

Start with the real brand: product, audience, existing marks and where the identity must work. Inspect actual source assets before tracing or redesigning. Separate a faithful cleanup of an existing mark from a proposed new identity; do not silently present a new design as the current official logo.

Choose a defensible construction principle from the brand's name or activity. Test silhouette and negative space before adding color, lighting or presentation. A recognizable mark should survive a monochrome print, a small favicon and a large sign. Typography and kerning are part of the identity, not an afterthought beside an icon.

For each credible direction, explain the connection to the brand in one concrete sentence. Avoid attaching invented symbolism to an arbitrary shape. Similarity research can identify obvious conflicts; it cannot prove worldwide originality or trademark availability.

Deliver the files the user actually needs:

- Editable SVG symbol and horizontal lockup, with clean viewBox, no clipped strokes and no unnecessary embedded raster images.
- Light, dark and monochrome versions; favicon treatment simplified deliberately where needed.
- PNG exports for convenient use, keeping the SVG as the master.
- A compact identity sheet: palette, type roles, minimum practical size, clear space, approved variations and a few actual application examples.
- A 3D adaptation only when it serves the brief. Preserve the recognizable silhouette. Keep an editable scene or procedural generator and export GLB when a reusable model is part of the deliverable.

Compare real rendered marks at 16, 24, 48 and 128 pixels; optically adjust where necessary. Inspect joins, counters, accidental tangencies, centering and light/dark contrast. Do not rely on attractive mockups to conceal a weak mark.

If a font is outlined, retain an editable text/source version and record its license. Source all imagery and fonts with usage rights suitable for the intended output. Use actual export tools; never rename a PNG to SVG or claim a native 3D file was generated without opening or validating it.

Keep the scope set by the user. A request for a 3D rendering of the existing logo does not by itself require a rebrand or six unrelated new marks.
